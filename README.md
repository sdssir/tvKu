# tvKu
For the tvKu / Live TV interface we designed, the playlist source was not hard-coded in the mockup itself. The intended flow is that the app loads an IPTV playlist from a configured source, usually one of these:  an M3U/M3U8 URL from your IPTV provider a local .m3u file or an Xtream Codes API if your provider gives server URL + username + password
